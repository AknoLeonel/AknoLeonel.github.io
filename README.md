# aknoleonel.github.io

Portfólio de Leonel Paiva: uma constelação interativa com os sites que desenvolvi e que estão em produção.

**Ao vivo:** https://aknoleonel.github.io

- O site "se compila" na abertura: um `npm run build` de mentira faz o deploy dos 16 projetos e a página se monta em wireframe (uma vez por sessão; `Esc` pula).
- Cada estrela é um projeto; clique para abrir uma prévia ao vivo.
- Filtros por área: automotivo, saúde, esporte e eventos, negócios e projetos pessoais.
- HUD com o progresso do "build" conforme a rolagem e 6 conquistas para desbloquear.
- Paleta de comandos com `Ctrl/⌘ K` ou `/` para buscar projetos e seções.
- Easter egg: ↑↑↓↓←→←→BA.
- HTML, CSS e JavaScript em um único arquivo, com [GSAP](https://gsap.com) (ScrollTrigger, SplitText, ScrambleText) via CDN. Sem GSAP o site continua funcionando, só sem animação. Respeita `prefers-reduced-motion`.
